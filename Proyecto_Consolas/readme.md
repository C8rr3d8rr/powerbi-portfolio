## 📊 Análisis Comercial y Forecast de Consolas

Este proyecto presenta un dashboard desarrollado en Power BI enfocado en el análisis integral de ventas de consolas, permitiendo evaluar el desempeño comercial de cada marca, el comportamiento de las ventas y las proyecciones de demanda (forecast).

El objetivo principal es facilitar la toma de decisiones estratégicas mediante el análisis de datos comerciales, permitiendo identificar tendencias de mercado, optimizar inventarios y proyectar oportunidades de crecimiento para cada fabricante de consolas.

El dashboard permite visualizar métricas clave como:

Ventas totales por marca
Forecast de ventas mensuales
Cantidad de consolas disponibles por marca
Participación de mercado
Crecimiento y variación de ventas
Comparativo histórico de desempeño
Rotación de inventario
Top marcas y modelos más vendidos

## 🛠 Herramientas utilizadas
- Power BI
- DAX (Data Analysis Expressions)
- odelado de datos (modelo estrella)
- Visualización de datos
- Forecasting y análisis predictivo
- Storytelling con datos

## 📈 Insights principales
Las marcas líderes concentran el mayor volumen de ventas y participación de mercado.
El forecast permite identificar temporadas con mayor demanda de consolas.
Algunas marcas presentan alta rotación de inventario y crecimiento sostenido en ventas.
